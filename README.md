# Oh My Zsh Auto Install Script

**Description:**  
This script automatically installs Oh My Zsh and sets up two plugins: `zsh-autosuggestions` and `zsh-syntax-highlighting`. It also configures the terminal theme to "bira" for a customized appearance.

## Usage

1. **Download the script**  
Save the installation script to your computer.

2. **Run the script**  
Open your terminal and execute:
```bash
bash install-ohmyzsh.sh
```
Make sure you have sudo privileges.

## Features

- Automatically installs zsh and Oh My Zsh
- Sets the terminal theme to "bira"
- Installs `zsh-autosuggestions` and `zsh-syntax-highlighting` plugins
- Modifies `.zshrc` configuration for you

## Prerequisites

- Ubuntu/Debian-based system (uses `apt`)
- `sudo` access

## After Installation

- Restart your terminal or run `zsh` to use Oh My Zsh with the new settings and plugins.
